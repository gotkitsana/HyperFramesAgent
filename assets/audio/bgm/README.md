# BGM Library — สาระไม่น่ารู้

เพลงพื้นหลัง 4 mood ตามจังหวะของคลิป

## โครงสร้าง

```
bgm/
├── mystery-intro/       ← เพลงเปิด (0-15s)  ลึกลับ/ระทึก
├── fast-paced-body/     ← ช่วงเล่าเรื่อง     จังหวะเร็ว
├── tension-climax/      ← ไคลแม็กซ์          บีบคั้น
└── cliffhanger-outro/   ← ปิดท้าย/CTA        ทิ้งห้วง
```

## ที่มาแนะนำ (ฟรี / ใช้เชิงพาณิชย์ได้)

| แหล่ง | ลิงก์ | หมายเหตุ |
|---|---|---|
| **Pixabay Music** | https://pixabay.com/music/ | Filter: Dark / Cinematic / Suspense — ไม่ต้อง attribute |
| **YouTube Audio Library** | https://www.youtube.com/audiolibrary | Filter: Genre=Cinematic, Mood=Dark/Dramatic |
| **Uppbeat (free tier)** | https://uppbeat.io/ | ต้อง credit แต่ใช้ฟรี (15 ดาวน์โหลด/เดือน) |
| **Freesound (CC0)** | https://freesound.org/ | filter CC0 only |

## คำค้นที่ใช้ได้ผล

- mystery-intro: `dark mystery`, `cinematic suspense`, `eerie intro`, `dark ambient`
- fast-paced-body: `cinematic action`, `tense underscore`, `documentary dark`, `pulse`
- tension-climax: `dramatic build up`, `cinematic tension`, `apocalyptic`
- cliffhanger-outro: `cinematic ending`, `dark outro`, `dramatic stinger`

## ไฟล์ที่คาดหวัง

ตั้งชื่อแบบนี้เพื่อให้ค้น/อ้างอิงง่าย:
```
mystery-intro-pixabay-001.mp3
fast-paced-body-uppbeat-pulse-007.mp3
```

วางอย่างน้อย mood ละ **1-2 track** ก่อน เพื่อเริ่มทำคลิปได้

## Format

- ✅ `.mp3` (320kbps หรือ 192kbps พอ)
- ✅ `.m4a` / `.aac`
- ❌ หลีกเลี่ยง `.wav` (ไฟล์ใหญ่เกิน)
