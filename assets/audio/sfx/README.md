# SFX Pack — สาระไม่น่ารู้

เสียงประกอบ 7 หมวด ครอบคลุมจังหวะตัดต่อสไตล์ดาร์ก fast-paced

## โครงสร้าง

```
sfx/
├── whoosh/         ← ใช้กับ transition / cut (5-10 ตัว ยิ่งดี ให้สลับใช้)
├── typewriter/     ← เมื่อ text overlay ขึ้นทีละตัว
├── beep-alarm/     ← เน้นจุดอันตราย / warning
├── impact-boom/    ← Hook punch / accent หนัก ๆ
├── heartbeat/      ← Tension ช่วงไคลแม็กซ์
├── glitch/         ← Jump cut / digital artifact
└── notification/   ← CTA / กล่อง subscribe
```

## ที่มาแนะนำ (ฟรี + ใช้เชิงพาณิชย์ได้)

| แหล่ง | ลิงก์ | หมายเหตุ |
|---|---|---|
| **Freesound** | https://freesound.org/ | filter **CC0** only (ไม่ต้องเครดิต) |
| **Pixabay Sound Effects** | https://pixabay.com/sound-effects/ | ฟรี ไม่ต้องเครดิต |
| **Zapsplat** | https://zapsplat.com/ | ต้องสมัครสมาชิกฟรี + ใส่เครดิต |
| **Mixkit** | https://mixkit.co/free-sound-effects/ | ฟรี ใช้เชิงพาณิชย์ได้ |

## คำค้นแยกหมวด

| หมวด | คำค้น |
|---|---|
| whoosh | `whoosh`, `swoosh transition`, `cinematic whoosh`, `sweep` |
| typewriter | `typewriter key`, `typing single`, `keyboard click` |
| beep-alarm | `alarm beep`, `warning siren`, `red alert`, `tension beep` |
| impact-boom | `cinematic impact`, `boom bass drop`, `trailer hit`, `braam` |
| heartbeat | `heartbeat slow`, `heart pulse`, `bass thump` |
| glitch | `glitch transition`, `digital glitch`, `vhs glitch` |
| notification | `pop notification`, `subscribe ding`, `bell pop`, `youtube bell` |

## จำนวนที่แนะนำ (MVP)

- whoosh: **5-10 ตัว** (ต้องมีหลายตัวเพื่อไม่ซ้ำใน 60 วินาที shorts)
- impact-boom: **3-5 ตัว**
- ที่เหลือ: **1-2 ตัว/หมวด** ก็พอ

## Format

- ✅ `.mp3` หรือ `.m4a` (ขนาดเล็ก, โหลดเร็วใน preview)
- ✅ `.wav` ได้ ถ้าสั้น <2 วินาที
